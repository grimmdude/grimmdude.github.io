## Overview

This is a personal portfolio and blog website built with Jekyll using the [al-folio](https://github.com/alshedivat/al-folio) theme. The site is deployed to GitHub Pages and accessible at https://grimmdude.com.

## Development Commands

### Local Development
```bash
# Install dependencies
bundle install

# Serve site locally with live reload (http://localhost:4000)
bundle exec jekyll serve

# Build site to _site/ directory
bundle exec jekyll build
```

### System Requirements
- Ruby (version 3.1+ recommended based on GitHub Actions workflow)
- Bundler
- ImageMagick (required for jekyll-imagemagick plugin to generate responsive WebP images)

## Architecture

### Jekyll Structure

**Content Collections:**
- `_posts/` - Blog posts with front matter (layout, title, categories, excerpt)
- `_projects/` - Project showcase items (output to /projects/:path/)
- `_news/` - News/announcements (output to /news/:path/, limited to 5 on homepage)
- `_pages/` - Static pages like about.md (permalink: /)
- `_bibliography/` - BibTeX files for academic citations (managed by jekyll-scholar)

**CSS Framework:**
- Bootstrap 5.3.8 (`assets/css/vendor/bootstrap.min.css`) - base styling framework

**Theme Components:**
- `_layouts/` - Page templates (about, post, page, bib, distill, archive-*, default)
- `_includes/` - Reusable components (figure, pagination, projects, news, social, metadata)
- `_sass/` - SCSS stylesheets (_base, _layout, _themes, _variables, _syntax-highlighting, _distill)
- `assets/` - Static files (css/, img/, js/, pdf/, bibliography/)

**Custom Plugins** (`_plugins/`):
- `beautify.rb` - HTML beautification using HtmlBeautifier (controlled by `beautify: true/false` in _config.yml)
- `minify.rb` - HTML minification using HtmlCompressor (controlled by `minify: true/false` in _config.yml)

### Configuration (_config.yml)

**Key Settings:**
- Site metadata: title, name, email, description
- Social integration: GitHub, Instagram usernames
- Google Analytics: enabled with tracking ID
- Blog pagination: enabled
- Collections: news (limit: 5), projects
- Jekyll Scholar: APA style citations from `_bibliography/papers.bib`
- ImageMagick: generates responsive images at 480px, 800px, 1400px widths in WebP format
- Optional features: Most disabled (darkmode, masonry, math, tooltips, etc.)

**Important Exclusions:**
- bin/, Gemfile, Gemfile.lock, vendor/ are excluded from Jekyll build

### Deployment

GitHub Actions workflow (`.github/workflows/jekyll.yml`):
1. Triggers on push to master branch
2. Sets up Ruby 3.1 with bundler cache
3. Installs ImageMagick via apt-get
4. Builds with `bundle exec jekyll build --baseurl` for GitHub Pages
5. Deploys to GitHub Pages environment

**Important:** ImageMagick must be installed before building due to jekyll-imagemagick dependency.

## Content Authoring

### Blog Posts
- Front matter required: layout (post), title, categories, excerpt
- Filename format: YYYY-MM-DD-title.md
- Permalink structure: /blog/:year/:title/
- Archives auto-generated by year, tag, and category

### Projects
- Stored in `_projects/` directory
- Output to /projects/:path/
- Categories enabled for organization

### News Items
- Stored in `_news/` directory
- Layout defaults to 'post'
- Only latest 5 shown on homepage

### Academic Citations
- Add entries to `_bibliography/papers.bib`
- Uses APA citation style
- Bibliography template: bib layout
- BibTeX filters: latex, smallcaps, superscript

## Jekyll Plugins

The site uses these plugins (defined in Gemfile):
- jekyll-archives - Archive pages by year/tag/category
- jekyll-diagrams - Diagram rendering support
- jekyll-email-protect - Email obfuscation
- jekyll-feed - RSS feed generation
- jekyll-github-metadata - GitHub metadata integration
- jekyll-imagemagick - Responsive WebP image generation
- jekyll-paginate-v2 - Blog pagination
- jekyll-scholar - Academic bibliography management
- jekyll-sitemap - Sitemap generation
- jekyll-target-blank - External links in new tabs
- jekyll-twitter-plugin - Twitter embeds
- jemoji - Emoji support

## Theme Customization

The site is based on al-folio theme. When making changes:
- Override theme files by placing modified versions in corresponding directories
- SCSS variables defined in `_sass/_variables.scss`
- Theme switching controlled by `_sass/_themes.scss`
- Base styles in `_sass/_base.scss` (10KB+, main stylesheet)
